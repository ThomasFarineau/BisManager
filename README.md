# BisManager

**BisManager** is a lightweight World of Warcraft addon that enhances the default character and inspect frames with Best-in-Slot tracking, item level overlays, enchant/gem checks, and group gear reports.

---

## Features

### 🎯 Best-in-Slot (BiS) Tracking
- Visual **BiS badges** on each equipment slot of the character frame — instantly see if your equipped item is BiS or what to aim for
- Color-coded indicators: **green** = BiS equipped, **red** = upgrade available, **yellow** = empty slot
- Tooltip showing all configured BiS alternatives per slot, with equipped item comparison
- **Pre-built BiS profiles** from multiple data sources (Archon, Method, Wowhead, Murlok.io), updated regularly — works out of the box, no setup needed

### 📋 Profile Management
- Create, import, export, copy, and delete BiS profiles
- **Inspect copy**: right-click any inspected player to import their visible gear as a new profile
- Per-character profile storage with easy switching
- Built-in profile presets auto-loaded based on your class and spec

### 📊 Item Level Display
- **ilvl overlay** on every equipment slot (character frame, inspect frame, bags)
- Color-coded by item quality
- **Average ilvl summary** on the inspect frame with at-a-glance comparison
- Detailed per-slot ilvl in tooltips

### ✨ Enchant & Gem Checks
- Visual indicators for **missing enchants** on enchantable slots
- **Empty socket detection** for items with ungemmed slots
- Works on both your character and inspected players
- Toggle on/off with a single click

### 👥 Group Item Level Report
- **Minimap button** to open a group ilvl overview window
- Shows item level of all party/raid members at a glance
- Class-colored names for easy readability
- Right-click the minimap icon to open settings

### ⚙️ Configuration
- Full settings panel: toggle features, adjust scale, opacity, and display options
- Slash commands: `/gm` for quick access
- Per-slot BiS editing via the config UI
- Source URL display for each profile, linking back to the original guide

## Data Sources

BisManager ships with pre-generated BiS data from:

| Source | Type | URL |
|--------|------|-----|
| **Archon** | Raid & M+ | [archon.gg](https://www.archon.gg/wow) |
| **Method** | Raid, M+ & Overall | [method.gg](https://www.method.gg/) |
| **Wowhead** | Overall | [wowhead.com](https://www.wowhead.com/) |
| **Murlok.io** | M+ | [murlok.io](https://murlok.io/) |

BiS presets are auto-generated by the scraper tool in `tools/` and stored in `Data/GeneratedBiS.lua`.

## Installation

1. Download or clone this repository
2. Place the `BisManager` folder in:
   ```
   World of Warcraft/_retail_/Interface/AddOns/
   ```
3. Restart WoW or `/reload` — the addon is ready to use with built-in BiS data

---

## Scraper Tool (for contributors)

The `tools/` folder contains a Node.js scraper that fetches BiS lists from all providers and generates the Lua data file.

```bash
cd tools
npm install

# Scrape all providers and generate Lua
npm run scrape

# Scrape a single provider
npm run scrape -- --provider archon

# Regenerate Lua from existing JSON data
npm run generate
```
